M4B Editor — Windows x86_64

FR
Ouvrir le MSI pour une installation par utilisateur avec raccourci Demarrer.
Alternative portable : extraire TOUT le ZIP et lancer m4b-editor.exe ou le .cmd.
FFmpeg et ffprobe sont fournis a cote des executables ; ne pas les separer.
Aucune installation multimedia ni modification de PATH n'est requise.
L’extraction ZIP et RAR fonctionne hors ligne.
Conserver projets et actifs hors du dossier d'installation. Transporter tout
le dossier projet avec ses actifs ; verifier les anciens chemins absolus.
Pour un lecteur, utiliser le M4B exporte. Garder une sauvegarde.
L'export refuse l'ecrasement et necessite une destination acceptant les liens
physiques (normalement NTFS) et environ 11,5 Mo/minute de PCM plus le resultat.
Les mises a jour verifient un manifeste Ed25519 ; cela n'est pas Authenticode.
Windows peut afficher editeur inconnu/SmartScreen. Ne pas desactiver globalement
la securite. La verification au demarrage n'autorise pas l'installation :
consentement explicite requis ; enregistrer puis arreter lecture/export.
La validation Linux/Wine historique ne remplace pas les tests natifs Windows.

EN
Open the MSI for per-user installation with a Start menu shortcut.
Portable alternative: extract the ENTIRE ZIP and launch m4b-editor.exe or .cmd.
Keep bundled ffmpeg/ffprobe beside the application. No media installation or
PATH change is required. ZIP and RAR import work offline.
Keep projects/assets outside the install directory; transport the whole project
folder and verify older absolute source paths. Use exported M4B for players.
Keep backups. Export refuses overwrite, requires hard-link support (normally
NTFS) and about 11.5 MB/minute of PCM staging plus encoded output.
Ed25519 update signatures are not Authenticode: unknown-publisher/SmartScreen
warnings are possible. Do not globally disable Windows security. Startup
checking does not authorize installation: explicit consent is required; save
and stop playback/export first. Historical Linux/Wine checks are not native
Windows validation.

FFmpeg 8.0.1 / zlib 1.3.1 / LAME 3.100 corresponding sources: accompanying -media-sources.zip.
Keep/publish this sidecar with the binary release. Not needed to run the app.
